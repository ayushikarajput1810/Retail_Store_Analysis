# 📊 Retail Sales Analytics & Business Intelligence Dashboard

## 📌 Project Overview

An end-to-end Power BI Business Intelligence project designed to analyze
retail sales performance across customers, products, orders, returns,
stores, regions, and payment methods.

The project transforms transactional data into interactive dashboards
that provide actionable insights for business decision-making.

---

## 🎯 Business Objective

The objective of this project is to analyze retail business performance
and identify trends in:

- Sales and profitability
- Customer behavior
- Product performance
- Order trends
- Returns
- Regional performance
- Store performance
- Payment methods

---

## 📐 Data Modeling

The project uses a dimensional data model consisting of:

### Fact Table

- `fact_orders`

### Dimension Tables

- `dim_customers`
- `dim_products`
- `dim_stores`
- `dim_date`

The model enables efficient filtering and analysis across
customers, products, stores, regions, and time.
